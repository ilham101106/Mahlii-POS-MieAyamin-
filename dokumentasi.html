1. RINGKASAN SISTEM

MieAyamin POS adalah aplikasi Point of Sale (Kasir) & Manajemen Operasional Warung Mie Ayam modern yang dibangun menggunakan standar teknologi Web Native (HTML5, Vanilla CSS3, JavaScript ES6+, Web LocalStorage API) — tanpa framework atau dependensi backend luar.

Aplikasi ini bersifat offline-first: semua data tersimpan langsung di browser melalui localStorage, dapat dioperasikan tanpa koneksi internet, dan mendukung fungsionalitas penuh Kasir POS, antrean Dapur (KDS), laporan omset, manajemen stok bahan baku, serta pengelolaan foto katalog produk.

3. MODUL KASIR (POS) — index.html / kasir.html

Modul utama aplikasi. Halaman ini adalah layar pertama yang terbuka ketika aplikasi diakses. Berfungsi sebagai antarmuka pencatatan pesanan, pembayaran, dan pengelolaan transaksi kasir warung.

Tampilan Halaman Kasir (POS) — http://localhost:3000/
📸 Tampilan standar layar kasir dengan kategori menu, grid produk, dan panel keranjang pesanan.

Fitur Utama Modul Kasir:

  • Klasifikasi Kategori Menu (Pill Tab Filter): Semua Menu | 🍜 Makanan & Mie Ayam | 🍹 Minuman & Aneka Jus | 🍢 Extra Topping | 🍿 Aneka Kerupuk
  • Mode Tampilan Grid / List: Tombol beralih antara tampilan Card Grid 📱 (visual foto produk) dan Daftar Ringkas 📋.
  • Pencarian Cepat: Input teks real-time dengan shortcut keyboard / atau F2.
  • Hold Order & Drafts: Tombol ⏸️ Hold untuk menahan pesanan aktif dan 📋 Draft untuk memuat kembali pesanan sementara kapan saja.
  • Tipe Pesanan: Pilihan 🍽️ Dine-in, 🛍️ Bungkus, dan 🛵 Ojol pada setiap pesanan.
  • Modal Pembayaran Multimetode: Mendukung Tunai (dengan Quick-Cash: Uang Pas / 20rb / 50rb / 100rb, dan Touch Numpad Grid), QRIS, dan Transfer/EDC. Kalkulasi kembalian otomatis real-time.
  • Audio Synthesizer (Web Audio API): Membunyikan suara chime khas kasir saat transaksi sukses diselesaikan.
  • Struk Thermal Printable: Modal struk siap cetak dengan rincian transaksi lengkap (ID, tanggal, item, total, kembalian).
  • Beralih Role: Tombol 🔑 Beralih Role di header untuk pindah ke Mode Dapur (KDS) atau Mode Owner (Admin PIN 9999).

4. MODUL DAPUR (KDS) — dapur.html

Kitchen Display System untuk area dapur warung. Secara otomatis menerima pesanan baru dari Modul Kasir melalui localStorage dan menampilkannya dalam antrean masakan real-time.

Tampilan Halaman Dapur (KDS) — http://localhost:3000/dapur.html
📸 Layar dapur Obsidian Dark Theme dengan antrean pesanan, live timer, dan indikator warna urgensi masakan.

Fitur Utama Modul Dapur:

  • Obsidian Dark Theme: Latar gelap (#0f172a) kontras tinggi, optimal untuk layar area dapur yang terpapar cahaya berlebih.
  • Live Order Timer Ticker: Menghitung durasi waktu sejak pesanan masuk (⏱️ 04:15).
  • Indikator Warna Urgensi Masakan:
    • 🟢 Hijau: < 5 menit (Baru Masuk, Santai)
    • 🟡 Kuning Amber: 5–10 menit (Perlu Diproses Segera)
    • 🔴 Merah Pulse Berkedip: > 10 menit (Sangat Mendesak / Prioritas Tertinggi!)
  • Toggle Status Pesanan: Menunggu ➔ Sedang Dimasak ➔ Selesai ✅
  • Notifikasi Suara Antrean Baru: Audio sintetis berbunyi secara otomatis saat pesanan baru dikirim dari kasir.

5. MODUL OWNER / ADMIN DASHBOARD — admin.html

Panel manajemen bisnis yang dilindungi PIN keamanan. Digunakan oleh pemilik warung untuk memantau performa bisnis, mengelola stok bahan baku, dan mengatur katalog menu beserta foto produk.

🔐 PIN Keamanan Default Owner: 9999
Akses panel Admin hanya dapat dilakukan setelah memasukkan PIN yang benar melalui keypad. PIN ini dapat diubah melalui kode sumber di file js/admin.js dan js/kasir.js.
Tampilan Halaman Owner / Admin Dashboard — http://localhost:3000/admin.html
📸 Dashboard Owner dengan metric KPI, grafik omset penjualan per jam, top best seller, kelola stok, dan kelola foto menu produk.

Fitur Utama Modul Owner / Admin:

  • Analisis KPI Penjualan: Metric card Total Omset, Jumlah Transaksi, Estimasi Laba Bersih (45%), dan Total Pendapatan QRIS.
  • Grafik Batang Omset per Jam: Visualisasi distribusi omset per jam operasional warung (10:00–21:00).
  • Top 5 Best Seller: Peringkat menu terlaris berdasarkan jumlah penjualan real-time.
  • Kelola Stok Bahan Baku: Tabel persediaan stok (Mie basah, Ayam semur, Bakso, Pangsit, Jeruk, Teh, dll.) dengan:
    • Indikator badge ⚠️ Stok Menipis otomatis jika sisa stok < MinStock.
    • Tombol quick adjuster (− Qty +) untuk mengubah stok langsung dari tabel.
    • Tombol Restock +10 untuk penambahan cepat 10 unit.
  • Kelola Katalog Menu & Foto Produk:
    • Tombol ➕ Tambah Menu Produk Baru: Menambah produk baru beserta nama, kategori POS, harga, deskripsi, dan foto (via URL atau upload).
    • Tombol 📷 Edit Foto: Mengubah foto produk mana pun secara langsung.

8. PANDUAN PENGEMBANGAN & MAINTENANCE MASA DEPAN

A. Mengubah PIN Owner (Default: 9999)

Buka file js/admin.js dan js/kasir.js, cari teks '9999' dan ganti dengan PIN baru Anda.

B. Menambah / Mengubah Foto Produk

  • Via Aplikasi: Mode Owner (PIN 9999) ➔ Tab Kelola Menu & Foto ➔ Klik 📷 Edit Foto atau ➕ Tambah Menu.
  • Via Kode: Simpan foto baru di folder images/, lalu update properti image: 'images/foto_baru.png' pada DEFAULT_MENU di js/storage.js.

C. Menambah Kategori Menu Baru

Tambahkan tombol tab baru di kasir.html / index.html:

<button class="cat-tab" data-cat="snack">🍟 Aneka Snack</button>

Lalu tambahkan produk dengan properti cat: 'snack' pada DEFAULT_MENU di js/storage.js.
